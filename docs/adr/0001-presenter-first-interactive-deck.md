# 0001: Adopt Presenter-First Minimalist Structure with Intra-Slide Build Steps

The original deck was designed as a self-contained reading carousel with dense explanatory paragraphs. For live presentation delivery, this competed with the speaker and diluted visual punch. We decided to pivot to a Presenter-First model: stripping long prose in favor of punchy keywords, visual cards, and discrete reversible intra-slide build steps mapped to Arrow keys.
