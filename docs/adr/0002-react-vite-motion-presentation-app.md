# 0002: Build Presenter Deck with React, Vite, and Motion While Preserving Reading Companion

We decided to introduce a modern React + Vite + Motion application for the live Presenter Deck, while keeping the original standalone vanilla HTML/JS/CSS carousel untouched as a Reading Companion for self-study and documentation. React declarative state management and Motion's animation engine ensure rock-solid, reversible intra-slide build steps and fluid visual micro-interactions without fragile DOM manipulation.
