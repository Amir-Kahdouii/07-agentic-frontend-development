# 0005: Bespoke Hero Artifacts per Slide Grounded in VibeFarsi MCP

To maximize audience engagement and eliminate generic slide templates, each of the 8 slides centers on a bespoke, interactive Hero Artifact (such as a simulated terminal, live decision tree, token inspector, and pipeline subway map). Visual components, Persian design rules, and typographic tokens are directly informed and retrieved via the `vibefarsi` Model Context Protocol (MCP) server tools.
